
# Multidimensional Data Structures

A university project developed as part of the Computer Engineering and Informatics curriculum at the University of Patras.

The project explores the implementation and comparison of multidimensional data structures and similarity search techniques using Python.

## Project Overview

The main objective of this project is to study different data indexing and query processing techniques and investigate their application to multidimensional datasets.

The project includes implementations of tree-based data structures and a Locality-Sensitive Hashing (LSH) approach.

## Implemented Data Structures

- **KD-Tree:** Multidimensional data indexing and nearest-neighbor search.
- **Range Tree:** Data organization and range query processing.
- **R-Tree:** Hierarchical data indexing and query processing.
- **QuadTree:** Spatial data partitioning and multidimensional search.
- **Locality-Sensitive Hashing (LSH):** Hash-based indexing for similarity search.

## Technologies Used

- Python
- NumPy
- Pandas
- CSV

## Dataset

The project uses a Coffee Reviews dataset containing information about coffee products, including product names, roasters, roast types, countries of origin, and ratings.

The dataset is used to explore multidimensional indexing and query processing techniques.
